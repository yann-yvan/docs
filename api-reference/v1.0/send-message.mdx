<Warning>Legacy endpoint. In v2.0, use [`POST /conversations`](/api-reference/guides/start-a-conversation) to write first and `POST /conversations/{id}/messages` to reply. See [Migrate to v2.0](/api-reference/guides/migrate-to-v2).</Warning>

`POST https://shortext.ny-corp.io/api/messages/send`

| Field | Description |
| --- | --- |
| `channel` | `whatsapp` or `mail`. |
| `from` | The id of the sending channel: WhatsApp phone number id or mailbox id (`mbx_...`), as listed by `GET /api/v2.0/channels`. |
| `contact` | `identifier` (WhatsApp: E.164 without `+`) and `profile`, where `lastname` is **required**. See [Contact format](/api-reference/contact-format). |
| `message` | `type` and `content`, see [Message format](/api-reference/message-format). |

```json
{
  "channel": "whatsapp",
  "from": "532867649916076",
  "contact": { "identifier": "237699999999", "profile": { "lastname": "Mbarga" } },
  "message": { "type": "text", "content": { "text": "Your order A-1042 has left our warehouse." } }
}
```

On WhatsApp, text, media and interactive messages are only delivered within 24 hours of the contact's last message; outside that window, send a template.
