<Warning>Endpoint historique. En v2.0, utilisez [`POST /conversations`](/fr/api-reference/guides/start-a-conversation) pour écrire en premier et `POST /conversations/{id}/messages` pour répondre. Voir [Migrer vers la v2.0](/fr/api-reference/guides/migrate-to-v2).</Warning>

`POST https://shortext.ny-corp.io/api/messages/send`

| Champ | Description |
| --- | --- |
| `channel` | `whatsapp` ou `mail`. |
| `from` | Le canal d'envoi : identifiant du numéro WhatsApp ou nom d'utilisateur de la boîte mail. |
| `contact` | `identifier` (WhatsApp : E.164 sans `+`) et `profile`, où `lastname` est **obligatoire**. Voir [Format des contacts](/fr/api-reference/contact-format). |
| `message` | `type` et `content`, voir [Format des messages](/fr/api-reference/message-format). |

```json
{
  "channel": "whatsapp",
  "from": "532867649916076",
  "contact": { "identifier": "237699999999", "profile": { "lastname": "Mbarga" } },
  "message": { "type": "text", "content": { "text": "Votre commande A-1042 a quitté notre entrepôt." } }
}
```

Sur WhatsApp, les messages texte, médias et interactifs ne sont remis que dans les 24 heures qui suivent le dernier message du contact ; hors de cette fenêtre, envoyez un modèle.
