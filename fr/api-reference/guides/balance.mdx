---
title: Solde et mouvements du portefeuille
description: Lisez le solde de votre entreprise et les mouvements de son portefeuille, pour suivre vos dépenses ou rapprocher votre comptabilité.
---

Shortext débite le portefeuille de votre entreprise pour les messages, l'usage de l'IA et les abonnements, et le crédite quand vous le rechargez. Les endpoints demandent une clé avec **Voir les rapports financiers**.

## Solde

`GET /balance`

```json
{
  "balance": { "amount": 590.88, "currency": "EUR" },
  "local_balance": { "amount": 387590, "currency": "XAF" },
  "threshold": { "amount": 50, "currency": "EUR" },
  "low": false
}
```

| Champ | Description |
| --- | --- |
| `balance` | Le solde, dans la devise de facturation. |
| `local_balance` | Le même montant converti dans la devise du pays de votre entreprise, à titre indicatif. `null` s'il n'est pas disponible. |
| `threshold` | En dessous de ce montant, votre entreprise est invitée à recharger. |
| `low` | `true` quand le solde est sous le seuil. |

<Tip>Vérifiez `low` depuis une tâche quotidienne et alertez votre équipe financière avant que vos agents ne cessent de répondre faute de crédit.</Tip>

## Mouvements du portefeuille

`GET /balance/transactions` liste les mouvements réglés, les plus récents d'abord, 50 par page :

```json
{
  "current_page": 1,
  "data": [
    { "id": "...", "amount": -0.10613, "currency": "EUR", "description": "Message whatsapp (marketing) with an AI reply beyond the plan", "created_at": "2026-10-24T09:12:44+00:00" },
    { "id": "...", "amount": 100, "currency": "EUR", "description": "Recharge de compte initiée par l’utilisateur. Montant : 65 600 XAF HT (78 228 XAF TTC, soit 100 EUR).", "created_at": "2026-10-23T16:02:10+00:00" }
  ],
  "per_page": 50,
  "total": 2
}
```

`amount` est négatif pour un débit et positif pour un crédit. Un débit n'apparaît qu'une fois réglé.

- **Un mouvement par message.** Quand l'IA répond au-delà des réponses incluses dans votre forfait, le prix de la réponse IA s'ajoute aux frais du message : vous avez un seul débit par message, et non un débit séparé pour l'IA.
- **TVA sur les recharges.** La TVA dépend du pays de votre entreprise et s'applique au moment de la recharge : vous payez le montant TTC, et le libellé de la recharge indique le montant HT, le montant payé TTC et le montant crédité.

| Filtre | Description |
| --- | --- |
| `type` | `debit` ou `credit`. |
| `from`, `to` | Une période. |
